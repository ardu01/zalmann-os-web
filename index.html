02

Arquitectura y requisitos

Zalmann OS 0.8.0 es un perfil que se apoya en un Ubuntu que ya está instalado. No sustituye al sistema ni se arranca como distribución propia.

Base
Ubuntu con XFCE, en una sesión X11. Wayland y el uso con varios monitores no están validados.
Código
Python 3, GTK 3 y Cairo. El dock se dibuja por software y puede ampliar los iconos. No es cristal en vivo. El rebote y el punto de aplicación abierta no se probaron. La tecla Windows hace de Comando y Alt hace de Opción.
Herramientas
El README cita xprop, xdotool, xrandr, ImageMagick, rofi y herramientas de XFCE.
Instalación
El perfil se instala como usuario, dentro de la sesión, y no pide root. La pantalla de inicio de sesión y los fondos del sistema sí requieren un administrador.
Tema previsto
MacTahoe-Light-solid, con iconos y cursor. No están incluidos en el repositorio. Las cuatro capturas no redistribuyen el fondo ni el tema de la instalación del autor.
Compositor
Las sombras y las miniaturas de Mission Control dependen de picom.
Tienda
Catálogo local. El README describe 15 herramientas ArtCraft y 6 entradas de Windows, gratuitas. No ejecuta aplicaciones de macOS. Android queda pendiente de Waydroid. En la captura del autor se ve el botón Abrir; esa leyenda no acredita que cada herramienta se haya instalado o probado. Los iconos del lanzador tampoco lo acreditan.
Pruebas
14 pruebas de unittest resultaron correctas. No son una validación completa ni una prueba sobre hardware.

03

Estado y limitaciones

En desarrollo

El proyecto no está terminado. Lo que sigue es el límite conocido de la versión 0.8.0, no una promesa de lo que vendrá.

  • No es un sistema autónomo ni una distribución arrancable. No hay imagen ISO ni descarga en esta página.
  • El tema previsto, MacTahoe-Light-solid, y sus iconos y cursor no viajan con el repositorio.
  • El modo oscuro figura como «pronto». Los títulos de las ventanas no lo siguen.
  • Las sombras y las miniaturas de Mission Control dependen de picom.
  • El dock no es cristal en vivo. El rebote y el punto de aplicación abierta no se probaron.
  • Spotlight puede mostrar la carpeta Documents en inglés, como describe el README.
  • El control de Wi-Fi muestra el estado y no lo apaga.
  • Wayland y varios monitores no están validados. Android sigue pendiente de Waydroid.
  • Las 14 pruebas de unittest no cubren una validación completa ni el hardware.
  • Las cuatro capturas reales las facilitó el autor. No redistribuyen el fondo ni el tema de su instalación. Los datos de equipo visibles en Ajustes no se transcriben ni se toman como requisitos. Los iconos del lanzador no acreditan que cada aplicación se haya probado.
